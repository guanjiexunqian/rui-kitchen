# 锐锐的厨房 · 娟娟点菜

## 📱 娟娟手机安装（一次性）

1. 用 **Chrome 浏览器**打开：
   **https://guanjiexunqian.github.io/rui-kitchen/outputs/recipe.html**
2. 点右上角「⋮」→「**添加到主屏幕**」→ 确认
3. 桌面出现橙色「锐」图标，点开全屏，跟 App 一模一样
4. 以后锐锐改了菜谱，她那边打开自动就是新的

## 🔧 锐锐怎么更新菜谱

改完 `outputs/recipe.html` 后双击项目根目录的 `deploy.bat`，一分钟生效。

## 📦 数据说明

点菜记录、日历、照片、账本都存在**娟娟手机的浏览器**里（localStorage）：
- 换手机 / 卸载 Chrome / 清浏览器数据会丢
- 重要记录让她定期截图，或以后找锐锐加「导出备份」功能
